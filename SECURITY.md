# Security policy

## Supported versions

Security fixes are made for the latest released version only.

## Reporting a vulnerability

Do not open a public issue for security problems. Report them privately instead:

- Use GitHub's [private vulnerability reporting](../../security/advisories/new), or
- Send an email to info@merecs.de.

Describe the problem, the affected version, and how to reproduce it. We will confirm
receipt within 5 working days and keep you informed until the issue is resolved.
